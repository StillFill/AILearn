# SmartLearn

Aplicação web com **chat conversacional** orientado por inteligência artificial, pensado para apoiar **crianças e adolescentes** no estudo e na dúvida, com tom de **professor participativo** (explicação clara, reforço e curiosidade pedagógica).

## Objetivo do repositório

Este repositório concentra o produto **SmartLearn**: visão, plano, arquitetura e rastreamento de progresso em `docs/`, e a **aplicação web** em `apps/web/` (Next.js).

## Aplicação web

Instruções técnicas (comandos, pastas, env): [apps/web/README.md](apps/web/README.md).
